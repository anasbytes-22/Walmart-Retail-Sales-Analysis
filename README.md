# Walmart-Retail-Sales-Analysis

Project Overview

This project focuses on analyzing Walmart's historical retail sales data using Python. The goal is to understand sales trends, identify high-performing stores and departments, and discover seasonal patterns through Exploratory Data Analysis (EDA).

Objective

To analyze Walmart sales data and generate meaningful business insights that can support better sales planning and business decisions.

Business Problem

Retail businesses need to understand how sales change over time, which stores perform better, and which departments generate the most revenue. This project explores these questions using historical Walmart sales data.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

The project uses three datasets:

- "train.csv" – Historical weekly sales data.
- "stores.csv" – Store information and store types.
- "features.csv" – Additional information such as temperature, fuel prices, markdowns, CPI, and unemployment.

Project Workflow

1. Data Loading and Exploration
2. Data Cleaning and Preparation
3. Dataset Merging
4. Missing Value Analysis
5. Exploratory Data Analysis
6. Store and Department Performance Analysis
7. Monthly, Quarterly, and Yearly Sales Trends
8. Business Insights and Conclusions

Key Findings

- Total recorded sales were approximately $6.74 billion.
- The dataset contains 421,570 records.
- December recorded the highest average weekly sales in 2010 and 2011.
- Store 20 had the highest average sales among stores.
- Department 92 had the highest average sales among departments.
- Sales patterns showed seasonal variations across different months and quarters.

Business Insights

- Seasonal sales patterns can help businesses plan inventory and promotions.
- Store performance analysis can help identify successful locations.
- Department-level analysis can help businesses understand which product categories perform best.
- Historical sales trends can support better business planning.

Conclusion

This project demonstrates how Python can be used to clean, explore, and analyze retail sales data. The analysis helped identify important sales patterns and generate insights that can support data-driven business decisions.
